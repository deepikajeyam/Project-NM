# AI Learning & Study Assistant

An AI-powered study assistant using:

- Python
- Ollama
- RAG
- ChromaDB
- Streamlit
- Memory
- AI Agent

## Features

1. Ask questions from course materials
2. Upload PDF files
3. RAG-based answers
4. Student memory
5. Study plan generation
6. Quiz generation

## Technologies

Python 3.12
Ollama
Streamlit
ChromaDB
Sentence Transformers

## Run

Create virtual environment:

python -m venv venv

Activate:

venv\Scripts\activate

Install packages:

pip install -r requirements.txt

Run application:

streamlit run app.py
